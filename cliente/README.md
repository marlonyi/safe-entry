# Admin Residencial - Paquete de Instalación

Sistema de administración para conjuntos residenciales con control de acceso vehicular.

## Requisitos

- Windows 10/11 (64-bit)
- Docker Desktop: https://www.docker.com/products/docker-desktop/
- 8 GB RAM mínimo
- 20 GB espacio en disco

## Instalación

1. Instale Docker Desktop y reinicie su equipo
2. Abra Docker Desktop y espere que el icono esté verde
3. Descomprima esta carpeta en `C:\AdminResidencial`
4. Ejecute `instalar.bat`
5. Edite el archivo `.env.local` con sus credenciales
6. Acceda a http://localhost:5000

## Archivos incluidos

| Archivo | Descripción |
|---------|-------------|
| `instalar.bat` | Instalador (ejecutar primera vez) |
| `iniciar.bat` | Inicia los servicios |
| `detener.bat` | Detiene los servicios |
| `.env.local.example` | Plantilla de configuración |
| `docker-compose.yml` | Configuración de servicios |
